# Almaher Public Digital Identity Hub

بطاقة الهوية الرقمية العامة للماهر للصيانة: صفحة ثابتة خفيفة تعرض بيانات الهوية العامة، نطاق الخدمة، وسائل الاتصال، والملفات الاجتماعية الرسمية.

> هذا المستودع ليس تطبيق الخدمة الإنتاجي. الموقع الإنتاجي هو [almaher-est.com](https://almaher-est.com).

## Architecture

- `index.html` — صفحة هوية دلالية قابلة للتصفح عبر الروابط الداخلية.
- `data/almaher.json` — بيانات الكيان العامة المراجعة.
- `data/social-profiles.json` — سجل الملفات الاجتماعية الرسمية.
- `assets/js/app.js` — تحميل البيانات وعرضها وإتاحة قائمة الهاتف.
- `assets/js/constellation.js` — خلفية كوكبات Canvas تفاعلية بلا مكتبات خارجية.
- `assets/css/site.css` — التصميم الداكن، RTL، الزجاج، والتجاوب.

## Local preview

يحتاج تحميل JSON إلى خادم محلي؛ لا تفتح الصفحة عبر `file://`.

```powershell
python -m http.server 8000
```

ثم افتح `http://localhost:8000`. GitHub Pages منشور من فرع `main` في جذر المستودع: <https://almahers.github.io/info/>.

## Content policy

لا تضاف إلا الحقائق العامة المراجعة. يقتصر نطاق الخدمة على الغسالات الأوتوماتيكية وغسالات الصحون ومجففات الملابس في مكة المكرمة. لا يضيف هذا المشروع إحصاءات أو شهادات أو ضمانات أو ادعاءات اعتماد غير موثقة.
